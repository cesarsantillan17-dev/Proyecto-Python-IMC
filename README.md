# Calculadora de IMC

## Descripción
Programa desarrollado en Python para calcular el
Índice de Masa Corporal (IMC) de una persona.

## Objetivo
Aplicar los fundamentos de Python mediante la
captura dinámica de datos y operaciones aritméticas.

## Datos solicitados
- Nombre
- Edad
- Peso en kilogramos
- Estatura en metros

## Fórmula utilizada

IMC = Peso / (Estatura ** 2)

## Tecnologías utilizadas
- Python
- Git
- GitHub
